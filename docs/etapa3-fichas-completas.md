### Supino declinado  `decline_bench_press`

*novo (Bloco A) · revisão profissional pendente*

| Campo | Valor |
|---|---|
| Nome alternativo | Supino declinado com barra |
| Grupo | Peito |
| Músculos secundários | Tríceps braquial, Deltoide anterior |
| Equipamento | Barra |
| Categoria | Força |
| Padrão de movimento | Empurrar horizontal |
| Dificuldade | Intermediário |
| Unilateral | não |
| Sugestão | 4 × 8-12, descanso 90 s |
| Vídeo / imagem | vazio |

**Descrição:** Supino no banco declinado, com ênfase na parte de baixo do peitoral.

**Como fazer:**
1. Prenda as pernas no apoio do banco declinado e deite com os olhos abaixo da barra.
2. Segure a barra um pouco mais aberta que os ombros e tire do suporte com os braços estendidos.
3. Desça a barra controlando até tocar a parte de baixo do peito.
4. Empurre de volta até estender os cotovelos, sem tirar as costas do banco.

**Erros comuns:**
- Descer a barra no pescoço ou no meio do peito.
- Abrir demais os cotovelos (90° do tronco).
- Quicar a barra no peito.

**Cuidados:** Faça com alguém ajudando na saída e na volta da barra. Evite se a posição de cabeça para baixo causar tontura ou se tiver pressão alta descontrolada.

**Tags de busca:** supino, peito inferior, declinado, barra

**Alternativas:** Supino reto, Mergulho nas paralelas, Supino na máquina

| Padrão de movimento | Adução horizontal |
| Dificuldade | Iniciante |
| Unilateral | não |
| Sugestão | 3 × 10-15, descanso 60 s |
| Vídeo / imagem | vazio |

**Descrição:** Abertura e fechamento dos braços no banco reto, isolando o peitoral.

**Como fazer:**
1. Deite no banco reto com um halter em cada mão, braços estendidos acima do peito e palmas viradas uma para a outra.
2. Com os cotovelos levemente dobrados, abra os braços em arco até sentir o peito alongar.
3. Feche os braços pelo mesmo caminho, como se abraçasse uma árvore.

**Erros comuns:**
- Dobrar e esticar os cotovelos durante o movimento (vira supino).
- Descer os halteres muito abaixo da linha do banco.
- Usar carga alta e perder o controle na parte de baixo.

**Cuidados:** Comece leve: a posição aberta força o ombro. Evite descer além do confortável se tiver dor ou instabilidade no ombro.

**Tags de busca:** crucifixo, peito, halteres, isolamento, fly

**Alternativas:** Voador (peck deck), Crossover na polia, Crucifixo inclinado com halteres

| Dificuldade | Intermediário |
| Unilateral | não |
| Sugestão | 4 × 8-12, descanso 90 s |
| Vídeo / imagem | vazio |

**Descrição:** Remada com a barra T (ou barra presa no canto), tronco inclinado à frente.

**Como fazer:**
1. Fique com uma perna de cada lado da barra, joelhos levemente dobrados.
2. Incline o tronco à frente com a coluna neutra e segure a pegada.
3. Puxe a barra em direção ao abdômen, aproximando as escápulas.
4. Desça devagar até estender os braços, sem arredondar as costas.

- Arredondar a coluna durante a puxada.
- Levantar o tronco a cada repetição para ajudar a carga.
- Puxar só com os braços, sem mexer as escápulas.

**Cuidados:** Mantenha a coluna neutra o tempo todo. Evite ou use carga leve se tiver dor lombar; a remada apoiada no peito é uma opção mais segura.

**Tags de busca:** remada, costas, barra t, cavalinho, espessura

**Alternativas:** Remada curvada, Remada baixa na polia, Remada unilateral com halter
