### Supino declinado  `decline_bench_press`

*novo (Bloco A) · revisão profissional pendente*

| Campo | Valor |
|---|---|
| Nome alternativo | Supino declinado com barra |
| Grupo | Peito |
| Músculos secundários | Tríceps braquial, Deltoide anterior |
| Equipamento | Barra |
| Categoria | Força |
| Padrão de movimento | Empurrar horizontal |
| Dificuldade | Intermediário |
| Unilateral | não |
| Sugestão | 4 × 8-12, descanso 90 s |
| Vídeo / imagem | vazio |

**Descrição:** Supino no banco declinado, com ênfase na parte de baixo do peitoral.

**Como fazer:**
1. Prenda as pernas no apoio do banco declinado e deite com os olhos abaixo da barra.
2. Segure a barra um pouco mais aberta que os ombros e tire do suporte com os braços estendidos.
3. Desça a barra controlando até tocar a parte de baixo do peito.
4. Empurre de volta até estender os cotovelos, sem tirar as costas do banco.

**Erros comuns:**
- Descer a barra no pescoço ou no meio do peito.
- Abrir demais os cotovelos (90° do tronco).
- Quicar a barra no peito.

**Cuidados:** Faça com alguém ajudando na saída e na volta da barra. Evite se a posição de cabeça para baixo causar tontura ou se tiver pressão alta descontrolada.

**Tags de busca:** supino, peito inferior, declinado, barra

**Alternativas:** Supino reto, Mergulho nas paralelas, Supino na máquina

### Roda abdominal  `ab_wheel_rollout`

*novo (Bloco A) · revisão profissional pendente*

| Campo | Valor |
|---|---|
| Nome alternativo | Rollout |
| Grupo | Abdômen |
| Músculos secundários | Latíssimo do dorso, Transverso |
| Equipamento | Roda abdominal |
| Categoria | Força |
| Padrão de movimento | Isometria de core |
| Dificuldade | Avançado |
| Unilateral | não |
| Sugestão | 3 × 6-10, descanso 60 s |
| Vídeo / imagem | vazio |

**Descrição:** Rolar a roda à frente e voltar, mantendo o abdômen firme.

**Como fazer:**
1. Ajoelhe e segure a roda à frente dos joelhos.
2. Role a roda à frente devagar, sem deixar a lombar afundar.
3. Vá só até onde conseguir manter a posição.
4. Volte puxando com o abdômen.

**Erros comuns:**
- Deixar a lombar afundar.
- Ir longe demais logo no começo.
- Voltar puxando só com o quadril.

**Cuidados:** Exercício avançado. Comece com amplitude curta. Evite com dor lombar.

**Tags de busca:** roda abdominal, rollout, core, abdômen

**Alternativas:** Prancha abdominal, Canoa (hollow hold), Dead bug (inseto morto)

| Campo | Valor |

| Músculos secundários | Glúteos, Adutores |
| Equipamento | Máquina |
| Categoria | Força |
| Padrão de movimento | Agachamento |
| Dificuldade | Iniciante |
| Unilateral | não |
| Sugestão | 3 × 8-12, descanso 90 s |
| Vídeo / imagem | vazio |

**Descrição:** Agachamento na máquina pêndulo, com as costas apoiadas.

**Como fazer:**
1. Apoie as costas e os ombros nas almofadas, pés no meio da plataforma.
2. Destrave e desça dobrando os joelhos até onde for confortável.
3. Suba empurrando a plataforma sem travar os joelhos.

**Erros comuns:**
- Tirar os calcanhares da plataforma.
- Joelhos caindo para dentro.
- Descer rápido e quicar no fundo.

**Cuidados:** Ajuste a amplitude à sua mobilidade. Evite com dor no joelho ao descer.

**Tags de busca:** agachamento, pêndulo, quadríceps, máquina

**Alternativas:** Agachamento no hack, Leg press 45°, Agachamento no Smith

*novo (Bloco A) · revisão profissional pendente*

| Campo | Valor |
|---|---|
| Nome alternativo | Bike |
| Grupo | Corpo todo |
| Músculos secundários | Quadríceps, Glúteos, Gastrocnêmio |
| Equipamento | Bicicleta |
| Categoria | Cardio |
| Padrão de movimento | Cardio |
| Dificuldade | Iniciante |
| Unilateral | não |
| Sugestão | 1 × 20 min |
| Vídeo / imagem | vazio |

**Descrição:** Pedalar na bicicleta ergométrica em ritmo contínuo ou intervalado.

**Como fazer:**
1. Ajuste o banco: com o pedal embaixo, o joelho fica levemente dobrado.
2. Comece com 3 a 5 minutos leves para aquecer.
3. Mantenha o ritmo combinado pelo tempo do treino.
4. Termine com alguns minutos leves.

**Erros comuns:**
- Banco baixo demais, forçando o joelho.
- Carga alta com pedalada muito lenta.
- Tronco jogado sobre o guidão.

**Cuidados:** Comece leve e aumente aos poucos. Pare se sentir dor no peito, falta de ar fora do normal ou tontura.

**Tags de busca:** bike, bicicleta, cardio, aeróbico

**Alternativas:** Elíptico, Remo ergômetro, Corrida/caminhada na esteira

| Equipamento | Barra |
| Categoria | Força |
| Padrão de movimento | Dobradiça de quadril |
| Dificuldade | Intermediário |
| Unilateral | não |
| Vídeo / imagem | vídeo já existente (não mudou) |

**Descrição:** Exercício composto para posterior de coxa, glúteos e lombar.

**Como fazer:**
1. Fique com os pés na largura do quadril, barra próxima às canelas.
2. Segure a barra e mantenha a coluna neutra.
3. Puxe o peso estendendo quadril e joelhos ao mesmo tempo.
4. Finalize em pé, ombros para trás, e retorne controladamente.

**Erros comuns:**
- Arredondar as costas.
- Barra longe das pernas.
- Hiperestender a lombar no topo.

**Cuidados:** Aprenda com acompanhamento e carga leve. Mantenha a coluna neutra. Evite carga alta com dor lombar.

**Tags de busca:** levantamento terra, terra, deadlift, barra

**Alternativas:** Stiff (levantamento terra romeno), Stiff com halteres, Extensão de quadril no banco 45°
